How this repository is organised

There is no single application built across the course. Each section is independent, so you can start anywhere and nothing you skip will break what you watch next.

  • src/app/sections/ — one folder and one page per section, with its demos inside
  • src/app/shared/ — the course card and mock data, reused across sections so the demos stay familiar
  • src/app/model/ — the Course type every demo works with

Every demo reads mock data, so nothing needs the backend running except Section 8.
